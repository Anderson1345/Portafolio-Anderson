Detalle

Interfaz

Lo que la persona ve y usa en el navegador: estructura, estilos e interacción.

  • HTML Lo uso
    Define la estructura y el contenido de una página.
  • CSS Lo uso
    Controla el diseño, los colores y la adaptación a cada pantalla.
  • Bootstrap 5 Lo uso
    Librería CSS para construir interfaces responsive más rápido.
  • JavaScript Lo uso · básico
    Agrega interacción a la página. Lo uso a nivel básico.

Detalle

Lógica

El servidor: recibe peticiones, aplica las reglas de la aplicación y responde.

  • Node.js En aprendizaje
    Permite ejecutar JavaScript en el servidor.
  • NestJS En aprendizaje
    Framework de Node.js para construir APIs organizadas por módulos.

Detalle

Datos

Dónde y cómo se guarda la información para consultarla después.

  • SQL Lo uso
    Lenguaje para crear tablas y consultar bases de datos relacionales.
  • PostgreSQL En aprendizaje
    Sistema de base de datos relacional.
  • Prisma En aprendizaje
    ORM que conecta el código con la base de datos y gestiona sus modelos.
